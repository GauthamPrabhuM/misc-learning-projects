# misc-learning-projects

Small projects I built while learning, mostly 2020 to 2022. None of them is a finished product. They were each a separate repo; I merged them here with their commit history intact.

## graphics/ (JavaScript, p5.js, 2020)

| Folder | What it is |
|---|---|
| `bezier-quadratic-curve` | Quadratic Bezier curve from three control points |
| `bresenham-line` | Bresenham's line algorithm |
| `bresenham-circle` | Bresenham's circle algorithm |
| `mandelbrot-set` | Mandelbrot set renderer |
| `double-pendulum` | Double pendulum simulation, following The Coding Train's tutorial |
| `bubble-sort-visualisation` | Bubble sort, animated bar by bar |
| `pathfinding` | A* search on a 50 x 50 grid |
| `codepen-sketch` | A CodePen experiment |

## ml-basics/ (2020 to 2021)

| Folder | What it is |
|---|---|
| `linear-regression-cpp` | Linear regression in C++ |
| `linear-regression-gradient-descent-cpp` | The same, fitted with gradient descent |
| `gradient-descent-python` | Gradient descent and multivariate linear regression in Python, plus a word-cloud notebook |
| `neural-network-from-scratch` | A small neural network in NumPy, no framework |
| `car-price-predictor` | Linear regression on a car price dataset |
| `heart-disease-logistic-regression` | Logistic regression classifier for heart disease |
| `sentiment-analysis` | Bag-of-words logistic regression sentiment classifier (scikit-learn) |
| `cifar10-cnn` | CNN classifier for CIFAR-10 in PyTorch |

## vision/ (OpenCV, 2021)

| Folder | What it is |
|---|---|
| `face-detection-haar-vs-lbp` | Haar and LBP cascade face detectors compared on the same test images |
| `number-plate-detection` | Licence plate localisation with contours |
| `canny-lane-experiment` | Early Canny edge test that became [LaneDetection](https://github.com/GauthamPrabhuM/LaneDetection) |
